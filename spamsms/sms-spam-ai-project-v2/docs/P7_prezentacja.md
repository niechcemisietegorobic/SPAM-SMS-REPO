# P7 — Prezentacja wyników

W prezentacji warto opowiedzieć projekt w tej kolejności:

1. Jaki problem rozwiązujemy: klasyfikacja SMS jako spam/ham.
2. Jaki mamy zbiór danych i dlaczego jest niezbalansowany.
3. Jak przygotowano stare ręczne cechy i jak regex pomaga je policzyć.
4. Jakie modele porównano: GaussianNB, KNN, TF-IDF + ComplementNB.
5. Co pokazał eksperyment z różnymi inputami dla GaussianNB.
6. Co pokazał eksperyment z RandomOverSampler i SMOTE.
7. Jakie są wyniki walidacji krzyżowej.
8. Jakie są końcowe wnioski.

Najważniejsze zdanie:

> Projekt nie tylko pokazuje najlepszy model, ale też sprawdza, jak na wynik wpływa wybór cech i resampling danych niezbalansowanych.
